# GitHub 연결 및 주소 설정

1. GitHub에서 piano-step이라는 빈 공개 저장소를 만듭니다. 무료 GitHub Pages를 사용할 수 있습니다.
2. 이 ZIP을 풀고 안의 파일과 폴더를 저장소 main 브랜치에 올립니다. .github/workflows/pages.yml도 포함합니다.
3. 저장소 Settings → Pages → Build and deployment → Source에서 GitHub Actions를 선택합니다.
4. Actions에서 Publish Piano Step 워크플로를 실행합니다. 완료 후 표시되는 주소를 사용합니다.

soohee713-debug 계정에서 piano-step 저장소를 사용할 때 기본 주소는 https://soohee713-debug.github.io/piano-step/ 입니다. 아직 게시된 주소는 아닙니다.

piano-step.HongTea.는 .hongtea 최상위 도메인이 등록되어 있지 않아 그대로 사용할 수 없습니다. 별도 주소를 원하면 보유한 등록 가능 도메인을 선택하고 GitHub Pages의 Custom domain과 해당 도메인의 DNS를 설정해야 합니다. 이 패키지는 미확인 도메인을 CNAME으로 지정하지 않습니다.

악보 읽기·공개 악보는 기존 서버를 사용합니다. 업로드는 기존 서버의 새 창으로 연결됩니다. 피아노 음원은 이 패키지 안에 포함했습니다. 기존 사이트를 계속 유지해야 악보 공유가 동작합니다.
