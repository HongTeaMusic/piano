# 피아노 스텝 · HONGTEA

GitHub Pages용 학생 연습실입니다. 학생 가입과 개인정보 입력이 없습니다. 연습 기록은 브라우저에만 저장됩니다.

## 게시
이 폴더의 전체 내용을 공개 저장소의 main 브랜치에 올리고 Settings → Pages → Source를 GitHub Actions로 설정합니다. 필요하면 Actions에서 Publish Piano Step을 직접 실행합니다.

상대 경로를 사용하므로 사용자 사이트와 /pianostep/ 프로젝트 사이트 모두에서 동작합니다.

## 악보와 교사 기능
학생용 화면은 GitHub Pages에서 실행됩니다. 악보 코드로 읽는 악보는 기존 관리 서버(https://piano-step-studio.soohee713.chatgpt.site)에서 가져옵니다. 선생님 공간은 기존 관리 서버의 별도 창에서 열리며, 교사 비밀번호나 쿠키를 GitHub에 저장하지 않습니다. 서버에는 학생 연습 기록을 전송하지 않습니다.

이 폴더에는 서버 소스·비밀번호·복구 코드·학생 기록·업로드된 악보 원본이 포함되지 않습니다.

## 기록
주소가 달라지면 이전 주소의 브라우저 기록은 자동 이전되지 않습니다. 기존 기록을 지우거나 외부로 전송하지 않습니다.
